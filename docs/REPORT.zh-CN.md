# v4实验报告

**最低真实R：103.85699706606101，达到R≤104目标。**

原始2048行冷启动，五种子软决策树，20轮×50组逆向后端真实评估。没有使用旧实验模型、额外标签或最好参数。单次实验耗时约6小时43分钟；共享GPU耗时不能推导稳定加速倍数。

## 结果与选点

相比v3的104.14030796010047降低0.2833108940394595。首次低于104是第18轮第13组（103.90327951393556）；最终最好为第20轮第49组（103.85699706606101）。后者在第二栋楼将ramping向resilience转移0.0005。
